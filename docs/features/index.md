# Features

What you can do with Gako, and how each feature preserves the zero-knowledge
guarantee.

!!! note "Draft"
    This section is an outline. Each feature will get its own page with concrete
    walkthroughs once the workflows are exercised end to end.

## Planned pages

- **Secrets** — storing passwords, API keys, certificates, and notes; structure
  and metadata.
- **Sharing and access** — granting access to other identities while keeping the
  server unable to read content.
- **Machine authentication** — non-human identities for automation and CI.
- **Recovery** — recovering access without handing keys to the server.

See [Concepts](../concepts/zero-knowledge.md) for the model these features are
built on.
